
# Лабораторная работа №2 — REST API на FastAPI

## Описание проекта

REST API для хранения интернет-ссылок. Приложение разработано с использованием FastAPI. Для хранения данных используется JSON-файл.

## Функциональные возможности

- Добавление новых интернет-ссылок.
- Получение списка всех ссылок.
- Получение ссылки по идентификатору.
- Удаление ссылки по идентификатору.
- Проверка входных данных с помощью Pydantic.
- Сохранение данных в JSON-файле.
- Запуск приложения в Docker-контейнере.

## Структура проекта

```text
project/
├── app/
│   ├── __init__.py
│   ├── main.py
│   ├── schemas.py
│   └── utils.py
├── data/
│   └── links.json
├── Dockerfile
├── compose.yaml
└── requirements.txt
```


### Пример объекта ссылки

```json
{
    "url": "https://example.com",
    "description": "Пример интернет-ресурса",
    "tags": ["example", "web"]
}
```

Идентификатор ссылки генерируется автоматически при добавлении записи.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL-репозитория>
cd <папка-проекта>
```



### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Запуск приложения

```bash
python -m uvicorn app.main:app --reload
```

После запуска приложение будет доступно по адресу:

`http://127.0.0.1:8000`

### Документация API

Интерактивная документация Swagger:

`http://127.0.0.1:8000/docs`

## Запуск через Docker

Для сборки Docker-образа и запуска приложения с помощью Docker Compose выполните команду:

```bash
docker compose up --build
```

После запуска приложение будет доступно по адресу:

`http://localhost:8000`

Для остановки контейнеров:

```bash
docker compose down
```

## Хранение данных

Данные приложения сохраняются в файле `data/links.json`.


## Назначение основных файлов

- `main.py` — содержит FastAPI-приложение и обработчики HTTP-запросов.
- `schemas.py` — содержит Pydantic-модели для проверки данных.
- `utils.py` — содержит функции чтения и записи JSON-файла.
- `links.json` — файл хранения интернет-ссылок.
- `Dockerfile` — инструкции для сборки Docker-образа.
- `compose.yaml` — настройки запуска приложения в Docker Compose.
- `requirements.txt` — список зависимостей Python.
